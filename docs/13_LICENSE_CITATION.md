# License, citation, and attribution

No software license is assigned by this planning pack. Before publishing the web repository or a public Hugging Face Space:

1. confirm ownership and permission for the supplied R/Python source;
2. choose an appropriate software license and add `LICENSE`;
3. review the licenses of runtime dependencies and bundled assets;
4. review the terms, citation requests, and acceptable-use requirements for Open Targets, ClinicalTrials.gov, Gene2Phenotype, gnomAD, EVA/ClinVar, Supabase, Render, Hugging Face, and any optional AI/literature provider;
5. add `CITATION.cff` with project title, authors, version, repository URL, release date, and preferred citation;
6. cite source databases and display retrieval/release metadata in exports;
7. do not use provider or institutional logos in a way that implies endorsement.

For an academic demonstration, also consider archiving a tagged release and documentation/example outputs in a DOI-capable repository. Do not archive credentials, caches containing restricted data, or user-generated records.

The application About page should distinguish:

- application authorship and version;
- upstream data sources and their release/retrieval dates;
- software dependencies;
- hosting providers;
- the optional AI provider/model when used;
- the scientific and non-clinical disclaimer.
